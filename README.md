# CuidadoSeguro Notification Service

Microservicio de notificaciones de Cuidado Seguro, desarrollado con Java y Spring Boot.

## Objetivo

Centralizar la gestión de notificaciones internas y el envío de correos electrónicos mediante procesamiento asíncrono con RabbitMQ.

## Funcionalidades planificadas

- Gestión de notificaciones internas.
- Envío de correos electrónicos mediante SMTP.
- Consumo de eventos desde RabbitMQ.
- Persistencia de notificaciones en MySQL.
- Manejo de errores, reintentos y Dead Letter Queues (DLQ).

## Estado del proyecto

En etapa inicial de configuración y desarrollo.

## Tecnologías

- Java
- Spring Boot
- RabbitMQ
- MySQL
- Git y GitHub
